# Logcomex Finance Board - Supabase

## Ordem correta
1. No Supabase, abra SQL Editor.
2. Cole e rode o conteúdo de `schema.sql`.
3. Depois suba este ZIP no Netlify por deploy manual.
4. O board já deve carregar os cards do Supabase.

## Atenção
A secret key não deve ser usada no frontend. Este projeto usa apenas a publishable key.
